# Rapid Fire Companion

Rapid Fire Companion is a project in development for working with GM Gen 4 LS ECU calibration data.

Rapid Fire Companion is a software project in development for working with GM Gen 4 LS ECU calibration data. Current development includes horsepower fitting, solver experiments, cam checks, and saving and reopening projects in the app’s native format.

This repository holds project documentation. Supported hardware, installation instructions, and download information will be added when they’re ready.

## Support

For questions, email [Rapid Fire Software Support](mailto:support@rapidfiresoftware.net). When reporting a problem, include the app version if available, what you were trying to do, and any error message you saw.
